# Free Tech Toolkit

> Cost and certificate terms can change. Entries distinguish free learning from optional paid certificates and limited free tiers.

## Computer science and programming

- [CS50x](https://cs50.harvard.edu/x/) — Harvard introduction to computer science. Learning and a CS50 certificate are free; edX verified certificates are optional and paid.
- [CS50P](https://cs50.harvard.edu/python/) — Harvard introduction to programming with Python.
- [MIT OpenCourseWare — EECS](https://ocw.mit.edu/search/?d=Electrical%20Engineering%20and%20Computer%20Science) — university course material, assignments and lectures.
- [OSSU Computer Science](https://github.com/ossu/computer-science) — complete self-taught computer science curriculum.
- [Teach Yourself Computer Science](https://teachyourselfcs.com/) — focused guide to core CS subjects.
- [Nand2Tetris](https://www.nand2tetris.org/) — build a computer from logic gates through software.
- [Saylor Academy Computer Science](https://learn.saylor.org/course/index.php?categoryid=9) — free self-paced courses and completion certificates.
- [The Missing Semester](https://missing.csail.mit.edu/) — shell, Git, editors, debugging and automation.
- [Exercism](https://exercism.org/) — free practice and mentoring across many languages.
- [Learn X in Y Minutes](https://learnxinyminutes.com/) — fast syntax-focused language introductions.

## Contribution rules

A useful contribution should add or update a legitimate resource and accurately describe its current cost and credential terms.

Do not add:

- Pirated courses, cracked software or leaked credentials.
- Affiliate links, URL shorteners or referral spam.
- Security material aimed at unauthorized access.
- Empty files or meaningless commits created only to manipulate contribution counts.
