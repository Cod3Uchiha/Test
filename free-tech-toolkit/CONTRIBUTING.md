# Contributing

Contributions are welcome when they improve accuracy, coverage or usability.

## Add or update a resource

1. Confirm that the official HTTPS page is reachable.
2. Verify the current cost model and certificate terms.
3. Add a concise, factual description in the correct category.
4. Clearly distinguish free learning from an optional paid verified certificate.
5. Open a pull request describing what you verified.

## Quality requirements

Resources should be legitimate, useful, legally accessible and reasonably maintained. Affiliate links, URL shorteners, copied paid courses, cracked software, piracy, malicious downloads and instructions for unauthorized access are not accepted.

## Commit quality

Every commit should represent real work: a verified resource, correction, feature, accessibility improvement, test or documentation update. Do not create empty, automated or backdated commits solely to manipulate GitHub contribution statistics.
